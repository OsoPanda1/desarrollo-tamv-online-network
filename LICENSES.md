# TAMV Online Network — License scope

**Policy in this branch:** Apache License 2.0 for original software and Creative Commons Attribution 4.0 International for authored narrative documentation.

The two licenses have different scopes. Do not interpret this file as proof that every file in the repository is owned by the maintainer or cleared for redistribution.

## Scope matrix

| Material | Default scope | Notes |
|---|---|---|
| Original application and interface code, components, libraries, scripts, tests, migrations, styles and build configuration | Apache-2.0 — see [LICENSE](LICENSE) | Only to the extent the relevant rights holder can grant those rights. File-specific notices take precedence. |
| Original narrative documentation in \`docs/**\`, plus project-authored Markdown explaining how to use, contribute to, or govern TAMV | CC BY 4.0 — see [LICENSE-DOCS](LICENSE-DOCS) | Attribution is required. Do not apply this scope to executable code samples, schemas, datasets, photographs, audio, video or models merely because they are embedded in a document. |
| Third-party code, fonts, icons, images, datasets, research papers, model weights, cultural materials, API specifications and provider assets | Their own license, terms or access conditions | The repository's license files do not relicense material owned by others. Inspect source notices and preserve required attribution. |
| Community-sensitive, personal, confidential, restricted or culturally governed data | No blanket permission granted by this notice | Technical accessibility and an open-data license do not replace consent, a lawful basis, community-defined rules or access controls. |
| Files with explicit per-file or directory license notices | The explicit notice | Record source, version and license when adding or replacing the material. |

## Attribution and source of authority

TAMV Online Network is an independent initiative originating in Mineral del Monte, Hidalgo, Mexico. Project materials identify Edwin Oswaldo Castillo Trejo, also known as Anubis Villaseñor, as founder and principal architect. A public author statement alone does not prove exclusive ownership of every contribution or third-party asset.

This policy applies only to works for which the relevant rights holder has authority to grant the stated license. Maintainers must retain third-party notices, inspect historical contributions before redistribution, and resolve disputed or unclear ownership before claiming that an item is cleared.

## Contributions

By intentionally submitting an original code contribution for inclusion, a contributor offers it under Apache-2.0 unless they clearly state otherwise before acceptance. Original narrative documentation submitted for inclusion is offered under CC BY 4.0 unless the contributor clearly states otherwise before acceptance. Contributors must have the rights needed to make that offer and must disclose third-party material.

TAMV does not require a contributor to publish personal data, confidential information, private community knowledge, credentials or undisclosed vulnerabilities.

## Limits

- A license grants copyright permissions; it does not certify security, accuracy, deployment, scientific review, accreditation or legal compliance.
- A citation, DOI, ORCID or hash is not itself a license.
- A hash identifies bytes; it does not prove that a statement is true or that the signer owns a key.
- The repository's public availability does not remove third-party rights, privacy restrictions or community protocols.
- Membership fees do not buy ownership of project code, institutional status, employment, project acceptance or guaranteed funding.

The scope separation above must remain aligned with file-level notices and be reviewed when the repository incorporates new materials or accepts contributions from additional rights holders.
